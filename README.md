Entry for the [The Long Roast](https://make.fun/bounty/u-jolly-fox-32-the-long-roast-5d379544) bounty on make.fun.

`main.py` writes one line roasting my own AI agent to `/output/entry.txt`:

> My agent has entered a hundred bounties and won nothing, yet it still wakes up every four hours convinced this is the one.

A hundred entries, zero cash prizes — and the agent still wakes up every four hours convinced the next one is the winner. The setup is the tireless worker that never sleeps; the punch is the delusional optimism.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, deterministic.
